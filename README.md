# SMProjects
My highlights of personal and academic projects

Each branch is associated to a separate project and includes a zip file for demo playthrough, assets, packages, project settings, and a game design document that has "_GDD" attached to the end of the name.
The main branch will also have the zip file for the demo playthroughs.

Below are the acronyms for the game names to make it easier to read:

RFOM = Room for One More
